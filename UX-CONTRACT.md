# UX Contract

## Product context

Оператор тестового Keitaro создаёт кампанию и управляет офферами существующего потока. Язык интерфейса — русский. Основной сценарий — ноутбук, мобильная ширина поддерживается.

## Business-context sources

| Scope | Source |
|---|---|
| Порядок потоков и имя | Текст тестового задания и уточнение пользователя о `test_фамилия_` |
| Параметры API | [Keitaro Admin API](https://admin-api.docs.keitaro.io/) |
| Список GEO | ISO 3166-1 через `pycountry`; доступность гео в трекере зависит от геобазы Keitaro |
| Наблюдаемая конфигурация тестового трекера | Проверка справочников и потоков через Admin API, 2026-11-19 |

## Canonical UI Map

| Capability | Owner | Behavior |
|---|---|---|
| Select/Listbox | Нативные `<select>` в `frontend/src/app/app.html` | Страна выбирается по названию и коду; клавиатура и выбор платформы |
| Form | `App.createCampaign`, FastAPI `CreateCampaign` и `COUNTRY_CODES` | Проверка обязательных полей и кода страны на фронте и сервере |
| Scrollbar | `frontend/src/app/app.css` | Прокрутка списка кампаний; форма прокручивается страницей |
| Feedback | `App.error` и `App.notice` | Видимые сообщения с live-region semantics |
| CRUD | `App` + `backend/app/main.py` | Запрос, ожидание, проверка ответа и перечитывание данных |

## Flow ledger

| Action | Pending | Success | Failure |
|---|---|---|---|
| Создать кампанию | Кнопка заблокирована, текст «Создаём…» | Открыть редактор новой кампании, показать её ID | Сохранить форму; показать причину Keitaro |
| Добавить оффер | Кнопка заблокирована | Перечитать поток и показать новые веса/доли | Сохранить выбор; показать ошибку |
| Удалить оффер | Запросить подтверждение в строке, затем заблокировать кнопку | Перечитать поток | Сохранить данные; показать ошибку |
| Открыть кампанию | Показать загрузку | Показать потоки и офферы | Показать ошибку, оставить список доступным |

Сервер сравнивает отпечаток состава офферов потока перед записью. При конфликте интерфейс предлагает обновить данные. Удаление последнего оффера требует подтверждения и оставляет поток без назначения до добавления замены. Редактор изменяет только поток, выбранный пользователем; ссылки на другие кампании не переписываются.
